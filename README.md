# YoutubeTrend Analyzer — Hardcord Targeting Tool

Identify the best trending YouTube channels and programs for 6-second commercial placements. Built for hardcord/ad placement businesses that embed short ads into Teledrama and YouTube creator content.

---

## Setup

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Configure your API key

```bash
cp .env.example .env
```

Open `.env` and replace `your_api_key_here` with your YouTube Data API key:

```
YOUTUBE_API_KEY=AIzaSy...
REGION_CODE=LK
MAX_RESULTS=50
```

### 3. Get a YouTube Data API key

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Create a new project (or select an existing one)
3. Navigate to **APIs & Services → Library**
4. Search for **"YouTube Data API v3"** and click **Enable**
5. Go to **APIs & Services → Credentials**
6. Click **Create Credentials → API key**
7. Copy the generated key into your `.env` file

> **Note:** The free tier provides 10,000 quota units per day. Each run of this tool uses approximately 100–200 units depending on the number of results.

## Usage

### Basic — analyze trending videos for Sri Lanka (default)

```bash
python analyzer.py
```

### Specify region and result count

```bash
python analyzer.py --region LK --max-results 50
```

### Filter by category

```bash
python analyzer.py --category 24        # Entertainment
python analyzer.py --category 25        # News & Politics
python analyzer.py --category 26        # Howto & Style
python analyzer.py --category 10        # Music
python analyzer.py --category 17        # Sports
python analyzer.py --category 20        # Gaming
python analyzer.py --category 27        # Education
python analyzer.py --category 28        # Science & Technology
```

### Output format

```bash
python analyzer.py --output html        # HTML report only
python analyzer.py --output csv         # CSV file only
python analyzer.py --output both        # Both (default)
```

### Show more/fewer results

```bash
python analyzer.py --top 10             # Show top 10 channels
python analyzer.py --top 30             # Show top 30 channels
```

### Combined example

```bash
python analyzer.py --region US --category 25 --max-results 50 --output html --top 15
```

## What the Hardcord Score Means

The **Hardcord Score** ranks channels by their suitability for 6-second ad placements using this formula:

```
score = (views / 1,000,000) × (likes / max(views, 1) × 100) × log10(max(subscribers, 1))
```

It combines three factors:

| Factor | What it measures | Why it matters |
|--------|-----------------|----------------|
| `views / 1,000,000` | **Reach** — total trending video views | More views = more impressions for your ad |
| `likes / views × 100` | **Engagement rate** — audience interaction | Engaged audiences are more receptive to ads |
| `log10(subscribers)` | **Audience size** (log-scaled) | Larger channels offer sustained reach |

### Score tiers (relative to the highest scorer in a run)

| Colour | Threshold | Recommendation |
|--------|-----------|----------------|
| **Green** | ≥ 66% of max score | Tier 1 — prioritise for placement |
| **Yellow** | 33–66% of max score | Tier 2 — good secondary targets |
| **Red** | < 33% of max score | Tier 3 — lower priority |

Channels with multiple trending videos in the same run have their stats combined before scoring, giving an accurate picture of their overall momentum.
